# Dual Evidence — Interactive Research Demo

[Open the demo](https://yongxifengc.github.io/dual-evidence-demo/)

- **Review workbench:** de-identified case excerpts, documented actions, learned treatment references, and cached predictive comparisons.
- **Rule microscope:** patient-specific supported sets compared with Direct core and Direct hull.
- **Research snapshot:** aggregate results from the single latent–Practice / single-GRU configuration.
- **Mechanism animation:** a separate explainer using fictional cases and schematic graphics.

Case excerpts are published following the project owner's confirmation of display authorization. PHYS labels are presentation aliases; times are relative to the reviewed decision. The repository contains only the minimal demonstration excerpts, not the original clinical database, patient identifiers, model weights, or credentials. Public display does not grant unrestricted rights to reuse source data.

The workbench replays existing outputs; it does not run live inference. Predicted trajectories are labeled separately from observed history. Manual action comparisons do not recompute the original review classification. This is a research demonstration, not treatment advice.
